# Prompts

Reusable, versioned prompt templates. Each file is a single prompt with
{{variables}} you fill in.

## Folders

| Folder | Use for |
|---|---|
| ideation/ | blog ideas, topic clusters, content calendars |
| drafting/ | blog posts, newsletters, LinkedIn, Twitter threads, video scripts |
| editing/ | rewrite tone, fact-check, summarize |
| seo/ | meta descriptions, keyword outlines, internal links |
| social/ | captions, hashtags |
| email/ | welcome sequences, newsletters |
| video/ | hooks, scripts |

## How to use

1. Open a prompt file.
2. Replace every {{variable}}.
3. Paste into your LLM (or load it from tools/<provider>/generate.py).
