# Blog Content Pipeline

End-to-end flow to generate and publish a blog post.

## Steps

1. Ideation — prompts/ideation/blog-ideas.md
2. Outline — prompts/seo/keyword-outline.md
3. Draft — prompts/drafting/blog-post.md
4. Edit — prompts/editing/rewrite-tone.md
5. SEO — prompts/seo/meta-description.md
6. Publish — tools/publishing/wordpress.md (or Ghost/Webflow)

## Automate it

    python automation/scripts/generate.py

## Output

Save drafts to samples/outputs/blog-post.md until ready to publish.
