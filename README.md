# AI Content Engine Playbook

A practical playbook for building an AI-powered content engine: architecture,
prompt engineering, content pipelines, deployment, and the tools that power it.

## Quickstart

1. Read `docs/01-architecture.md` for the big picture.
2. Use `prompts/` as reusable templates.
3. See `examples/` for sample input → output runs.
4. Check `docs/tools-and-references.md` for the tool stack.

## Repo map

| Path | Purpose |
|---|---|
| `docs/` | The playbook content |
| `prompts/` | Reusable prompt templates |
| `examples/` | Sample inputs and outputs |
| `scripts/` | Automation code |
| `assets/` | Diagrams and images |
| `assets/brand/` | Brand assets (logos, palettes, fonts) |
