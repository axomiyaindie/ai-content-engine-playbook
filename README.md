# AI Content Engine Playbook

</p>

An open-source playbook for **generating content with AI** — prompts, skills,
tools, automation, and end-to-end pipelines. Clone it, adapt it, ship content.

## What's inside

| Folder | What it gives you |
|---|---|
| `docs/` | Guides: architecture, prompting, pipelines, scaling, cost control |
| `prompts/` | Ready-to-use prompt templates (blog, social, email, SEO, video) |
| `skills/` | The "how" behind each tool: writing, research, SEO, editing, automation |
| `tools/` | Working scripts for OpenAI, Anthropic, Gemini, local LLMs |
| `samples/` | Sample inputs → outputs and workflows |
| `automation/` | Scripts + CI to run the pipeline end to end |
| `website/` | Reserved for the project website (built later) |

## Quickstart

1. **Pick your model** → `docs/tools/openai.md` (or anthropic / gemini / local-llm)
2. **Copy a prompt** → `prompts/drafting/blog-post.md`
3. **Run the script** → `tools/openai/generate.py`
4. **Automate it** → `automation/workflows/blog-pipeline.md`

## Who it's for

Writers, marketers, indie hackers, and developers who want a **repeatable AI
content pipeline** instead of ad-hoc ChatGPT sessions.
